# Security Policy

## Reporting Security Issues

We take the security of PDFtoAgent seriously. If you believe you have found a security vulnerability in this project, please report it responsibly.

### How to Report

Please do **NOT** open a public issue on GitHub. Instead, report security issues via:

* **Email:** babak.sh60@gmail.com
* **GitHub Private Vulnerability Reporting:** Through the [Security Tab](https://github.com/babaksh/PDFtoAgent/security/advisories) of this repository.

Please provide:
1. A description of the vulnerability.
2. Steps to reproduce the issue (proof-of-concept).
3. The potential impact.

We will acknowledge receipt within 48 hours and work on a fix promptly.
